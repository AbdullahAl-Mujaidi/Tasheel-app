# 🛠️ تسهيل - إدارة المهن البسيطة والأعمال الحرة

> **تسهيل** هو تطبيق جوال مبني بتقنية Flutter، يهدف إلى توفير نظام رقمي بسيط وسهل الاستخدام لأصحاب المهن الصغيرة والحرة.

---

## 📖 نظرة عامة (Overview)

يهدف هذا المشروع إلى تطوير تطبيق "تسهيل" كحل رقمي بديل عن الدفاتر الورقية التقليدية. يعاني أصحاب المهن البسيطة (كالخياطين، السباكين، الكهربائيين، والمحلات الصغيرة)  من عدم وجود نظام منظم لإدارة حساباتهم اليومية. يأتي هذا التطبيق ليسد هذه الفجوة من خلال واجهة عربية بسيطة وتقنية تعمل دون الحاجة لاتصال دائم بالإنترنت.

---

## 🚨 بيان المشكلة (Problem Statement)

يعاني أصحاب المهن البسيطة والأعمال الحرة من:
- **فقدان البيانات المالية** بسبب الاعتماد على الدفاتر الورقية المتناثرة.
- **صعوبة متابعة الديون والمستحقات** على العملاء.
- **عدم تنظيم معلومات العمال والرواتب** بشكل دوري.
- **عدم وجود تقارير مالية واضحة** تساعد في اتخاذ القرارات المصيرية للمشروع.
- - **جمود الحلول الحالية** التي لا تسمح بتخصيص الحقول وفق طبيعة كل مهنة.


الحلول الحالية إما معقدة وتحتاج لخبرة تقنية، أو مكلفة، أو لا تدعم اللغة العربية بشكل جيد، أو تعتمد على اتصال إنترنت قوي غير متوفر دائماً في البيئة المحلية.

---

## 💡 الحل المقترح (Proposed Solution)

يقدم تطبيق **تسهيل** نظاماً متكاملاً لإدارة المنشآت الصغيرة من خلال:
1.  **رقمنة العمليات اليومية** بالكامل.
2.  **واجهة مستخدم عربية** مبسطة تناسب جميع الفئات العمرية.
3.  **العمل دون اتصال بالإنترنت** (Offline-First) باستخدام قاعدة بيانات محلية.
5.  **نظام الحقول المخصصة (Custom Fields)** الذي يتيح للمستخدم التحكم الكامل في بياناته.

## ✨ الميزات الرئيسية (Key Features)

بناءً على تحليل الجمهور المستهدف، تم تحديد الميزات الأساسية ذات الأولوية العالية كما يلي:

| الميزة | الوصف |
| :--- | :--- |
| **📋 تسجيل الأعمال** | إضافة، تعديل، وحذف الأعمال المنفذة مع تفاصيل العميل، المبلغ، والتاريخ. |
| **👷 إدارة العمال** | تسجيل بيانات العمال وحساب الرواتب اليومية والأسبوعية بدقة. |
| **💸 إدارة المصروفات** | تسجيل المصروفات اليومية والأسبوعية مع إمكانية تصنيفها (مشتريات، إيجار، فواتير، إلخ). |
| **📊 التقارير المالية** | عرض تقارير واضحة للمساعدة في تحسين إدارة رأس المال. |
| **⚙️ الحقول المخصصة (الميزة الأهم)** | إمكانية إضافة حقول إضافية حسب رغبة المستخدم (نوع القماش، قياسات الجسم، نوع العطل، المسافة، إلخ) لجعل التطبيق مرناً لكل المهن. |


### 🌟 التفصيل الكامل لميزة "الحقول المخصصة" (Custom Fields)

هذه هي الميزة الأكثر تميزاً في تطبيق تسهيل، حيث تمنح المستخدم حرية تصميم نموذج العمل الخاص به:

- **إضافة حقول جديدة**: يمكن للمستخدم إضافة حقل نصي، رقمي، أو قائمة منسدلة (اختيارات) عند تسجيل عمل جديد.
- **التخصيص حسب المهنة**:
  - **الخياط**: يضيف حقول (نوع القماش، طول الكم، محيط الصدر، تاريخ التسليم).
  - **السباك**: يضيف حقول (نوع القطعة، مكان التركيب، سبب العطل).
  - **كهربائي السيارات**: يضيف حقول (نوع البطارية، قراءة العداد، نوع الحساس).
  - **مغسلة الملابس**: يضيف حقول (عدد القطع، نوع التنظيف، ملاحظات خاصة).
- **ظهور ديناميكي**: تظهر هذه الحقول تلقائياً في واجهة إضافة العمل وتفاصيله، ويتم حفظها مع باقي البيانات في قاعدة البيانات المحلية.

## 🎯 الجمهور المستهدف (Target Audience)

- أصحاب المهن البسيطة في اليمن (الخياطون، السباكون، الكهربائيون، أصحاب المغاسل).
- أصحاب المحلات الصغيرة والعيادات الخاصة (عيادات الأسنان، صيانة السيارات، صيانة الهواتف).
- المقاولون وأصحاب المشاريع الصغيرة.

## 🧰 التقنيات المستخدمة (Tech Stack)

تم اختيار الأدوات التالية لضمان الأداء العالي وسرعة التطوير والمرونة:

- **الإطار الأساسي (Framework):** Flutter (لإنشاء تطبيقات Android و iOS من كود واحد).
- **إدارة الحالة (State Management):** state (لإدارة الحالة بكفاءة وسهولة).
- **قاعدة البيانات (Local DB):** shared-preference (لتخزين البيانات محلياً دون الحاجة للإنترنت).
- **التعريب والتنسيق (Internationalization):** `intl` (لدعم التواريخ والأرقام باللغة العربية).
